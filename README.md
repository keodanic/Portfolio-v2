## ✨ Destaques da Arquitetura

- **Internacionalização Completa (`next-intl`):** Suporte nativo e dinâmico para Português (`pt`) e Inglês (`en`) com rotas localizadas (`/[locale]`) e metadados SEO otimizados por idioma.
- **Animações de Alta Performance (`GSAP` + `ScrollTrigger`):** Transições suaves, parallax multi-plano e *Glassmorphism UI* responsiva.
- **Vitrine de Engenharia & AppSec:**
  - **Featured Projects:** Cases reais detalhando arquitetura, stack, desafios de segurança (OWASP Top 10, RBAC, RLS) e métricas de impacto (*SimpliFit & Dumpy*, *MonitoringCO2 IoT FAPEMA*, *Freelant Platform*, *SimulaBET* e *Web Security Exploits*).
  - **Security Labs & Write-ups:** Acompanhamento de laboratórios práticos (*PortSwigger Web Security Academy*, *TryHackMe*, *Hacker101 CTF*) e acesso direto aos meus scripts de exploração automatizada e write-ups técnicos.
  - **Download Inteligente de Currículo:** Modal com seleção de idioma (Currículo PT-BR e US Resume EN-US).

## 🚀 Como Executar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/keodanic/Portfolio-v2.git
cd Portfolio-v2

# 2. Instale as dependências
npm install

# 3. Inicie o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:3000` (redirecionamento automático por idioma para `/pt` ou `/en`).
